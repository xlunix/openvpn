# Тестовые конфигурации VPN

Эта папка содержит тестовые конфигурации OpenVPN, которые используются **только** в тестовой ветке.

## Структура

```
config/
├── server/          # Конфигурация сервера для тестов
│   ├── server.conf
│   └── openssl.cnf
└── client/          # Конфигурация клиента для тестов
    ├── client.conf
    └── openssl.cnf
```

## Отличия от продакшн конфигураций

Тестовые конфигурации могут отличаться от продакшн:

1. **IP адреса** - используют тестовую подсеть `10.10.0.0/24`
2. **Проверка сертификатов** - используют `peer-fingerprint` для работы с самоподписанными сертификатами в OpenSSL 3.x
3. **Настройки для тестирования** - могут содержать дополнительные опции для отладки

## Ключи и сертификаты

Ключи и сертификаты **не хранятся** в этой папке. Они генерируются автоматически в контейнерах при первом запуске через скрипт `../scripts/setup-ca.sh`.

Директории `keys/` и `ca/` создаются автоматически в контейнерах и игнорируются git (см. `../.gitignore`).

## Важно

- Эти конфигурации **не должны** попадать в ветки клиента или сервера
- Продакшн конфигурации в `../../vpn-config/` **не изменяются** тестовой инфраструктурой
- Все изменения для тестирования делаются только в этой папке
