# Конфигурация OpenVPN клиента

Эта папка содержит все необходимые файлы для настройки и работы OpenVPN клиента с поддержкой белорусских криптографических алгоритмов через bee2evp engine.

## Структура папки

```
client/
├── client.conf          # Основной конфигурационный файл OpenVPN клиента
├── openssl.cnf          # Конфигурация OpenSSL для использования bee2evp
├── ca/                   # Сертификаты центра сертификации
│   └── ca.crt           # Сертификат CA для проверки сервера
├── keys/                 # Ключи и сертификаты клиента
│   ├── client.key       # Приватный ключ клиента (секретный!)
│   └── client.crt       # Сертификат клиента для аутентификации
└── easy-rsa/            # Утилиты для управления ключами (опционально)
```

## Назначение

Эта конфигурация предназначена для:
- Подключения клиента к VPN серверу
- Использования белорусских криптографических алгоритмов (BELT, BIGN, BASH) через bee2evp
- Безопасного обмена данными через зашифрованный туннель
- Тестирования и разработки VPN решений

## Основные файлы

### client.conf

Основной конфигурационный файл OpenVPN клиента. Определяет:
- Адрес и порт сервера для подключения
- Параметры сетевого интерфейса (TUN)
- Алгоритмы шифрования и аутентификации
- Параметры логирования и безопасности
- Настройки переподключения

**Ключевые параметры:**
- `remote` - адрес сервера (в тестовой среде: 10.9.0.1, в продакшене - реальный IP/домен)
- `proto` - протокол (udp/tcp)
- `cipher` - алгоритм шифрования
- `auth` - алгоритм аутентификации

### openssl.cnf

Конфигурация OpenSSL для загрузки bee2evp engine. Позволяет:
- Использовать белорусские алгоритмы вместо стандартных OpenSSL
- Настроить путь к библиотеке bee2evp
- Выбрать конкретные алгоритмы для использования

**Важно:** Путь к библиотеке (`dynamic_path`) должен соответствовать реальному расположению `libbee2evp.so` в системе.

## Использование

### Быстрый старт (тестовая среда)

1. Убедитесь, что все файлы на месте:
   ```bash
   ls -la /etc/openvpn/
   # Должны быть: client.conf, openssl.cnf, ca/ca.crt, keys/client.key, keys/client.crt
   ```

2. Запустите OpenVPN клиент:
   ```bash
   openvpn --config /etc/openvpn/client.conf
   ```

3. Проверьте подключение:
   ```bash
   ip addr show tun0  # Должен показать IP 10.8.0.2
   ping 10.8.0.1       # Ping сервера
   ```

### Развертывание в продакшене

#### Шаг 1: Подготовка файлов

1. **Скопируйте конфигурацию:**
   ```bash
   sudo cp client.conf /etc/openvpn/client.conf
   sudo cp openssl.cnf /etc/openvpn/openssl.cnf
   ```

2. **Скопируйте ключи и сертификаты:**
   ```bash
   sudo mkdir -p /etc/openvpn/{ca,keys}
   sudo cp ca/ca.crt /etc/openvpn/ca/
   sudo cp keys/client.key /etc/openvpn/keys/
   sudo cp keys/client.crt /etc/openvpn/keys/
   sudo chmod 600 /etc/openvpn/keys/client.key  # Только для чтения владельцем
   ```

3. **Проверьте путь к bee2evp:**
   ```bash
   # Убедитесь, что путь в openssl.cnf соответствует реальному расположению
   ls -la /build/build/install/lib/libbee2evp.so
   # Или укажите системный путь, если библиотека установлена системно
   ```

#### Шаг 2: Настройка для продакшена

**Измените в `client.conf`:**

1. **Адрес сервера:**
   ```conf
   # Замените тестовый адрес на реальный
   remote your-vpn-server.com 1194
   # Или используйте IP
   remote 203.0.113.1 1194
   ```

2. **Протокол (опционально):**
   ```conf
   # Для большей надежности через NAT используйте TCP
   proto tcp
   ```

3. **Логирование:**
   ```conf
   # Раскомментируйте для сохранения логов
   log /var/log/openvpn/client.log
   status /var/log/openvpn/client-status.log
   ```

4. **Алгоритмы шифрования:**
   ```conf
   # Можно использовать алгоритмы bee2evp вместо стандартных
   # cipher belt-256-cbc  # Белорусский алгоритм BELT
   # auth bash256         # Белорусский алгоритм BASH
   ```

#### Шаг 3: Запуск как сервис

**Systemd (Linux):**
```bash
# Создайте unit файл
sudo nano /etc/systemd/system/openvpn-client.service

[Unit]
Description=OpenVPN Client
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/openvpn --config /etc/openvpn/client.conf
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

# Включите и запустите
sudo systemctl enable openvpn-client
sudo systemctl start openvpn-client
```

## Варианты настройки

### Вариант 1: Минимальная конфигурация

Для быстрого тестирования достаточно:
- `client.conf` с базовыми настройками
- `openssl.cnf` для bee2evp
- Ключи и сертификаты

### Вариант 2: С дополнительной безопасностью

Добавьте в `client.conf`:
```conf
# TLS аутентификация
tls-auth /etc/openvpn/keys/ta.key 1

# Проверка отзыва сертификатов
crl-verify /etc/openvpn/ca/crl.pem

# Запрет на перенаправление трафика
redirect-gateway def1
```

### Вариант 3: С использованием алгоритмов bee2evp

Измените в `client.conf`:
```conf
# Используйте белорусские алгоритмы напрямую
cipher belt-256-cbc
auth bash256
```

**Примечание:** Убедитесь, что сервер поддерживает эти алгоритмы.

### Вариант 4: Для работы через NAT/Firewall

```conf
# Используйте TCP вместо UDP
proto tcp

# Увеличьте таймауты
keepalive 10 300

# Добавьте retry
resolv-retry infinite
```

## Тонкая настройка

### Производительность

1. **Отключите сжатие** (если трафик уже сжат):
   ```conf
   # Удалите или закомментируйте
   # comp-lzo
   ```

2. **Настройте буферы:**
   ```conf
   sndbuf 393216
   rcvbuf 393216
   ```

3. **Используйте UDP** (быстрее TCP):
   ```conf
   proto udp
   ```

### Безопасность

1. **Включите проверку отзыва сертификатов:**
   ```conf
   crl-verify /etc/openvpn/ca/crl.pem
   ```

2. **Используйте TLS аутентификацию:**
   ```conf
   tls-auth /etc/openvpn/keys/ta.key 1
   ```

3. **Ограничьте алгоритмы:**
   ```conf
   # Только сильные алгоритмы
   cipher AES-256-GCM
   auth SHA512
   ```

### Надежность

1. **Настройте автоматическое переподключение:**
   ```conf
   resolv-retry infinite
   persist-key
   persist-tun
   ```

2. **Логирование для отладки:**
   ```conf
   verb 4
   log /var/log/openvpn/client.log
   ```

## Персонализация для продакшена

### 1. Выбор алгоритмов шифрования

**Стандартные OpenSSL:**
```conf
cipher AES-256-CBC
auth SHA256
```

**Белорусские (bee2evp):**
```conf
cipher belt-256-cbc
auth bash256
```

**Современные (если поддерживается):**
```conf
cipher AES-256-GCM
auth SHA512
```

### 2. Настройка маршрутизации

**Только VPN трафик:**
```conf
# Не изменяйте маршруты по умолчанию
# (удалите или закомментируйте redirect-gateway)
```

**Весь трафик через VPN:**
```conf
redirect-gateway def1
```

**Выборочная маршрутизация:**
```conf
# Только определенные сети через VPN
route 192.168.1.0 255.255.255.0
```

### 3. DNS настройки

```conf
# Используйте DNS сервера VPN
dhcp-option DNS 10.8.0.1
dhcp-option DOMAIN vpn.local
```

### 4. Логирование и мониторинг

```conf
# Детальное логирование
verb 4

# Сохранение логов
log /var/log/openvpn/client.log
status /var/log/openvpn/client-status.log 10

# Ротация логов (настройте logrotate)
```

### 5. Оптимизация для мобильных устройств

```conf
# Быстрое переподключение
persist-key
persist-tun
resolv-retry infinite

# Экономия батареи
comp-lzo adaptive
```

## На что влияют настройки

### `remote` - адрес сервера
- **Влияет на:** Куда подключается клиент
- **Важно:** Должен быть доступен с клиентской машины
- **Продакшен:** Используйте доменное имя с DNS или статический IP

### `proto` - протокол
- **udp:** Быстрее, меньше накладных расходов, может терять пакеты
- **tcp:** Надежнее, работает лучше через NAT, медленнее
- **Влияет на:** Скорость и надежность соединения

### `cipher` и `auth` - алгоритмы
- **Влияют на:** Безопасность и производительность
- **AES-256-CBC:** Стандартный, хорошо поддерживается
- **belt-256-cbc:** Белорусский стандарт, требует bee2evp
- **Влияет на:** Скорость шифрования и требования к CPU

### `keepalive` - проверка соединения
- **Влияет на:** Обнаружение разрывов соединения
- **Меньшие значения:** Быстрее обнаруживают проблемы, больше трафика
- **Большие значения:** Меньше трафика, медленнее обнаружение проблем

### `verb` - уровень логирования
- **0-2:** Минимальное логирование
- **3:** Нормальный уровень (рекомендуется)
- **4-11:** Отладочная информация (может быть много)

## Устранение проблем

### Проблема: Не подключается к серверу

**Проверьте:**
1. Адрес сервера в `remote` доступен
2. Порт не заблокирован файрволом
3. Сертификаты CA совпадают на клиенте и сервере

### Проблема: bee2evp не загружается

**Проверьте:**
1. Путь к библиотеке в `openssl.cnf` правильный
2. Библиотека существует и доступна для чтения
3. Переменная `LD_LIBRARY_PATH` установлена

### Проблема: Медленное соединение

**Попробуйте:**
1. Использовать UDP вместо TCP
2. Отключить сжатие
3. Увеличить размер буферов
4. Проверить сетевую задержку

## Важные замечания

1. **Безопасность ключей:** Файл `client.key` должен быть защищен (chmod 600)
2. **Резервное копирование:** Сохраните копии ключей и сертификатов в безопасном месте
3. **Обновление сертификатов:** Регулярно обновляйте сертификаты перед истечением срока действия
4. **Мониторинг:** Настройте мониторинг статуса соединения для продакшена
5. **Логирование:** В продакшене включите логирование для аудита и отладки
