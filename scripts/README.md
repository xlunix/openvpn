# Документация по скриптам проекта OpenVPN + bee2evp

Эта папка содержит скрипты для автоматизации настройки, запуска и тестирования OpenVPN с поддержкой белорусских криптографических алгоритмов через bee2evp engine.

## Обзор скриптов

Скрипты разделены на три категории:

1. **Скрипты настройки и запуска** - подготовка окружения и запуск сервисов
2. **Скрипты тестирования** - проверка работоспособности VPN соединения
3. **Скрипты диагностики** - проверка состояния системы

## Скрипты настройки и запуска

### 1. setup-ca.sh

**Суть:** Генерирует все необходимые криптографические ключи и сертификаты для работы OpenVPN.

**Зачем нужен:**
- Создает центр сертификации (CA) для подписи сертификатов
- Генерирует ключи и сертификаты для сервера и клиента
- Создает параметры Диффи-Хеллмана для обмена ключами
- Генерирует TLS ключ для дополнительной защиты (опционально)

**Где используется:**
- Автоматически вызывается из `start-server.sh` и `start-client.sh`, если ключи отсутствуют
- Может быть запущен вручную для пересоздания ключей

**Когда запускается:**
- При первом запуске системы (ключи отсутствуют)
- При необходимости пересоздания ключей
- При добавлении новых клиентов (требует модификации)

**Последовательность работы:**
1. Создает директории для ключей и сертификатов
2. Генерирует приватный ключ CA (2048 бит)
3. Создает самоподписанный сертификат CA (срок действия 10 лет)
4. Генерирует ключ и сертификат для сервера
5. Генерирует ключ и сертификат для клиента
6. Создает параметры Диффи-Хеллмана (2048 бит, может занять время)
7. Генерирует TLS ключ (если OpenVPN доступен)

**Пример использования:**
```bash
# Автоматически (при отсутствии ключей)
docker compose exec openvpn-server /scripts/setup-ca.sh

# Вручную
./scripts/setup-ca.sh
```

**Важно:**
- Скрипт проверяет наличие ключей перед генерацией (не перезаписывает существующие)
- Генерация DH параметров может занять несколько минут
- Все ключи создаются с правами 600 (только для владельца)

### 2. start-server.sh

**Суть:** Запускает OpenVPN сервер с правильной конфигурацией и переменными окружения.

**Зачем нужен:**
- Настраивает переменные окружения для работы bee2evp
- Проверяет наличие конфигурации и ключей
- Создает TUN интерфейс для VPN
- Запускает OpenVPN сервер с нужными параметрами

**Где используется:**
- Используется как команда запуска в `docker-compouse-server.yml` для сервиса `openvpn-server`
- Может быть запущен вручную для отладки

**Когда запускается:**
- При запуске контейнера `openvpn-server` через `docker compose up`
- Автоматически при перезапуске контейнера

**Последовательность работы:**
1. Настраивает `LD_LIBRARY_PATH` для загрузки библиотек bee2evp
2. Устанавливает `OPENSSL_CONF` для использования bee2evp engine
3. Проверяет наличие конфигурационного файла `server.conf`
4. Создает директории для логов
5. Проверяет наличие ключей, при отсутствии запускает `setup-ca.sh`
6. Создает TUN интерфейс `/dev/net/tun` если его нет
7. Ищет исполняемый файл OpenVPN в стандартных местах
8. Запускает OpenVPN сервер с конфигурацией

**Пример использования:**
```bash
# Автоматически через docker-compose
docker compose up openvpn-server

# Вручную в контейнере
docker compose exec openvpn-server /scripts/start-server.sh
```

**Важно:**
- Скрипт требует прав root для создания TUN интерфейса
- Переменные окружения критичны для работы bee2evp
- При ошибке скрипт завершается с кодом ошибки (set -e)
